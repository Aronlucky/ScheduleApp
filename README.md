# Планер

Одностраничное приложение для планирования: весь код в одном файле `index.html`, без интернета и установки.

- Дни идут слева направо, дела внутри дня — сверху вниз.
- У каждого дела свой цвет (8 готовых + любой свой), время, заметка, отметка «выполнено».
- Нажмите на заголовок дня — откроется развёртка по часам (тоже слева направо, дела в часе сверху вниз).
- Данные хранятся в браузере (localStorage). В меню «⋯» есть резервная копия в файл и загрузка из неё.

## Как открыть на телефоне

- **Android:** скопируйте `index.html` на телефон и откройте его через файловый менеджер в Chrome/Firefox.
- **iPhone:** проще всего открыть через любой хостинг статических файлов (например, GitHub Pages) и добавить на экран «Домой».
