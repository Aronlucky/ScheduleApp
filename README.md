# Планер

Одностраничное приложение для планирования: весь код в одном файле `index.html`, без интернета и установки.

- Дни идут слева направо, дела внутри дня — сверху вниз.
- У каждого дела свой цвет (8 готовых + любой свой), время, заметка, отметка «выполнено».
- Нажмите на заголовок дня — откроется развёртка по часам (тоже слева направо, дела в часе сверху вниз).
- Дела можно перетаскивать: мышкой — просто тянуть, на телефоне — долгое нажатие и тянуть.
  Между днями, между часами, внутри дня (порядок дел без времени), на кнопки « » — на соседний день.
- Развёртка дня — шкала по часам: каждое дело — полоса от начала до конца. Пересекающиеся дела встают в разные строки,
  красная линия — текущее время. Полосу можно двигать (шаг 15 минут) и растягивать за правый край.
- Длительность задаётся в редакторе (15 мин … 3 ч или «до»), голосом («с 10 до 12», «на 2 часа») или растягиванием.
- Дела без времени лежат в панели слева; её можно свернуть в узкую полоску. Оттуда дела перетаскиваются на шкалу и обратно.
- Голосовой ввод: кнопка с микрофоном над «+». Скажите, например, «Завтра в 15:30 позвонить маме»,
  «В пятницу купить продукты», «12 ноября в 9 утра к врачу», «Через 2 часа забрать посылку» —
  дело сразу встанет в нужный день и час. Цвет можно назвать: «…красным цветом».
  Если браузер не умеет распознавать речь, ту же фразу можно надиктовать микрофоном клавиатуры или написать.
- Заметки — отдельный список фактов без времени (кнопка с листком вверху), с поиском.
- Аккаунты (кнопка с человечком): «На этом устройстве» — полностью офлайн; аккаунты по ключу синхронизируются
  через облако между устройствами. Регистрации нет — только выданные ключи. Всё шифруется на устройстве
  (AES-256-GCM, ключ шифрования выводится из ключа аккаунта через PBKDF2 + HKDF и никуда не отправляется),
  в облако уходит только шифр. Как создать облако — в `server/README.md`.
- Напоминания: в деле со временем — «В момент / за 5, 15, 30 мин / за 1 ч» (или голосом: «напомни …»).
  Пока планер открыт, уведомление показывает он сам; при закрытом — приходит push через облако
  (нужен аккаунт по ключу; на iPhone — планер на экране «Домой», iOS 16.4+).
- Работает без интернета: после первого открытия сайт сохраняется на устройстве (`sw.js`),
  изменения уходят в облако, когда сеть появится.
- Данные хранятся в браузере (localStorage). В меню «⋯» есть резервная копия в файл и загрузка из неё.

## Как открыть на телефоне

- **Android:** скопируйте `index.html` на телефон и откройте его через файловый менеджер в Chrome/Firefox.
- **iPhone:** файл из «Файлов», почты или мессенджера iOS показывает только как картинку — скрипты в таком просмотре не работают
  (планер в этом случае сам покажет подсказку). Нужно открыть страницу по ссылке в Safari:
  1. Выложите `index.html` на любой хостинг статических страниц, например GitHub Pages
     (Settings → Pages → Deploy from a branch; для приватного репозитория Pages доступен только на платных тарифах GitHub).
  2. Откройте ссылку в Safari → «Поделиться» → «На экран „Домой“». Планер откроется как приложение со своим значком.

  Добавить на экран «Домой» стоит обязательно: обычные сайты Safari может очистить после 7 дней без посещений,
  а у приложений с экрана «Домой» данные сохраняются. Резервная копия — в меню «⋯».
